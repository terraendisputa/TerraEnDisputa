Terra en disputa

A turn-based strategy game about conquering countries with dice, cards and pacts. Everyone plays in the browser, and you host the server.

Download How to play View the code

Three game modes

Classic

50 countries. With 4 to 6 players there are secret objectives plus the shared goal of holding 30 countries; with 2 or 3, whoever conquers all 50 wins.

Competitive

For 4 to 6 players, with clocks, automatic final rounds and scoring.

Reconquista

72 countries, situations that change every round, missiles, pacts and shared countries.

Features

  • Play on a computer, tablet or phone. Players don't install anything.
  • No accounts: each player joins with a link and picks a nickname and color.
  • Games are saved on the host's machine, not on someone else's server.
  • Windows and Linux packages that bundle everything they need.
  • Light and dark themes, music and a turn chime.
  • Open source under the AGPL-3.0 license.

The game interface is in Spanish.

Getting started

  1. Download the package for your system from Releases and extract the whole folder.
  2. Open ted.cmd on Windows or ./ted on Linux. The host panel opens, where you create the game.
  3. Copy the invitation and send it to your friends. Once everyone marks themselves as ready, the game starts.

First time? Follow the tutorial or read the rules in How to play.

To keep it running on a Linux server or to play remotely, follow the install guide (in Spanish).
